# Program Notes

Program notes are free-form notes kept with the program. Use them for anything the team needs to
remember that does not belong in the proposal or in an observation: decisions taken during Phase
II, instructions for the observer, a record of what changed and why.

Each note appears as a tab, and the tabs are ordered by title. A note has a **Title** and a body.
The body is written in the **Edit** tab and displayed in the **View** tab; it supports Markdown,
including tables, LaTeX-style maths and links.

Click the add button in the tile header to create a note. It is created with the title
`<New Note>`, which is selected so that you can type over it straight away. The trash button
deletes the note currently shown, and both actions can be undone with the undo and redo buttons
beside them.

### Private notes

Gemini staff can mark a note as **Private** using the checkbox next to the title; the checkbox is
only shown to staff. A private note is marked with a padlock in its tab header.

### Read-only access

Read-only Co-Investigators can read the notes but cannot add, edit or delete them. For them the
tile header shows no buttons and the text cannot be edited.
