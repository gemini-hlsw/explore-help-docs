# ToO Activation Ceiling

The ceiling is the most disruptive [Target of Opportunity](http://www.gemini.edu/observing/phase-i/too)
activation the program is allowed to use. It applies to the program as a whole; each observation
then declares its own **ToO Activation**, which may be anything up to the ceiling.

| Ceiling | Meaning |
|---|---|
| No Restrictions | No ceiling is set. Observations may use any activation. |
| None | The program contains no Targets of Opportunity. |
| Rapid | Observations may be triggered to be observed as soon as possible, but will not displace work already under way. |
| Interrupting | Observations may displace work already under way, where the running observation permits it. |

The three activations are listed in order of increasing disruption. An observation is a Target of
Opportunity exactly when its activation is above *None*; there is deliberately no level between
*None* and *Rapid*, because a trigger that is content to be observed whenever convenient is
scheduled like ordinary science.

The ceiling is set by Gemini staff and reflects what was approved for the program. Everyone else
sees it as plain text in the Program Details tile.

The matching figure on the proposal, also labeled *ToO Activation*, is not this value: it is the
most disruptive activation actually in use among the program's observations.
