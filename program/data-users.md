## Data Sharing

This tile controls who, besides the PI, can access the proprietary science data from this program through the
[Gemini Observatory Archive](https://archive.gemini.edu). The PI always has access and is not listed.
The number in the tile title is the number of people listed here who currently have data access.

The table lists every Co-Investigator, full-access or read-only, plus any **Data Only** users the PI has added.
Data Only users are not part of the proposal team; they are added only so that the data can be shared with them.

### Reading the table

**Name**, **Email** and **ORCID** identify the person. **Role** is their role in the program.
**Data Access** shows whether they can currently access the data. **Status** shows where their invitation stands:

- **Not Invited**: no invitation has been sent yet.
- **Invited**: an invitation has been sent but not yet accepted. Hover over the icon to see whether the email was delivered.
- **Confirmed**: the person has accepted the invitation and has a Gemini account.

### Managing data access

**Only the PI can make changes in this tile; everyone else sees it as read-only.**

To change whether someone can access the data, check or uncheck the box in the **Data Access** column.
This works for Co-Investigators as well as Data Only users, so you can, for example, give a Co-Investigator
access to the program in Explore but not to the data.

To share the data with someone who is not on the program:

1. Click the add button in the tile header (**Share data with a new user**). A new Data Only row appears.
2. Click the send button in that row and enter the person's email address, then click **Invite**.
   An invitation email is sent, and an invitation key is displayed. If you prefer to send the invitation another way,
   copy the key and send it yourself: it will not be shown again.
3. Check that the box in the **Data Access** column is checked.

While an invitation is pending you can cancel it with the revoke button in that row.
The trash button removes a Data Only user from the program; this cannot be undone.
Co-Investigators cannot be removed from this tile; to stop sharing data with one of them, uncheck their
**Data Access** box instead.
