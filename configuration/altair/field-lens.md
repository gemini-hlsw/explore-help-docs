# Field Lens

Whether Altair's field lens is in or out of the beam. The laser modes (LGS and LGS+P1) always use
it, so there is nothing to choose and the field does not appear for them; it is only shown for
the natural guide star (NGS) mode.

Left unset, it defaults to **Auto**, shown as *Auto (In)* or *Auto (Out)* depending on how far the
guide star is from the target — the placeholder tells you which the automatic choice would be.
Set it explicitly only if your configuration needs the other position.
