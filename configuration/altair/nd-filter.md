# ND Filter

A neutral density filter placed in front of Altair's wavefront sensor, for use with a very bright
natural guide star. It only attenuates light on the Altair path; the science beam is never
affected.

The field is disabled for the laser modes (LGS and LGS+P1), where it is forced to **Out**; it is
only editable for the natural guide star (NGS) mode.
