# Slit Spatial Offsets

The telescope offsets executed over the course of the observation.

Choose a named preset from the dropdown, such as **Nod along slit** or **Nod to sky**, or **No Offsets**, where the available choices are instrument-specific, or define your own set of custom offsets.

If you hand-edit a list away from a preset pattern, the dropdown shows **Custom**, and a revert icon appears to restore the default.

Each offset has a guiding toggle (the crosshair icon) for whether guiding is enabled for that position. 
Use the ✚ button on either list to add another position and the trash icon to remove one; the first position in a list cannot be removed.
