# Sky Offset Count

How many of the telescope positions in this dither pattern are dedicated sky offsets, taken away
from the target to sample blank sky, rather than on-target positions.

Raising the count from zero adds sky offsets to the **Sky Offsets** pattern below; lowering it
removes them from the end of that pattern. Setting it back to zero clears the Sky Offsets pattern
entirely, and that field is disabled while the count is zero.
