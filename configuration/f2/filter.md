# Flamingos-2 Filter

The filter used for the science exposure. The dropdown offers only the filters that support
spectroscopy, which excludes the narrow K-blue and K-red filters offered for imaging.

The filter's own central wavelength is used as the spectrum's central wavelength, so changing the
filter also changes where the spectrum falls on the detector.

A reset icon appears beside the field once it differs from the configuration's default, to revert
back to it.
