# GHOST Readout

How fast this detector is read out:

| Mode | Speed |
|---|---|
| Slow | Slowest, lowest read noise. Default for the Blue camera. |
| Medium | Default for the Red camera. |
| Fast | Fastest, highest read noise. |

A faster readout spends less time between exposures at the cost of a noisier read. Blue and Red
are set independently. A reset icon appears beside the field once it differs from the default,
to revert back to it.
