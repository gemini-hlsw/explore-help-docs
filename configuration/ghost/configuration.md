# Camera Configuration

GHOST has two independent detectors, Blue and Red, each with its own **Exposure Mode**,
**Binning** and **Readout** below. Configure each camera for the part of the spectrum it covers;
see **Binning** and **Readout** for what each of those settings trades off.

**Total / Step** shows the estimated time for one step on that detector, including its readout
overhead, and is recalculated whenever the configuration changes.
