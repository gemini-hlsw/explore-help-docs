# GMOS Spectroscopic Filters

Filters may be used during spectroscopy to block 2nd order contamination,
or to limit the wavelength range when using a MOS mask or two IFU slits.

There is not an explicit option for "no filter", however, clicking the "X" at the right of the selection will remove it.

A reset icon appears beside the field once it differs from the configuration's default, to revert back to it.

See the [GMOS components page](https://www.gemini.edu/instrumentation/gmos/components) for which filter pairs with which grating.
