# GMOS Filters

The blocking or order-sorting filter used with the grating, where one is needed to keep light
from adjacent spectral orders out of the spectrum. Not every grating needs one; **None** is
offered when it does not.

A reset icon appears beside the field once it differs from the configuration's default, to
revert back to it.

See the [GMOS components page](https://www.gemini.edu/instrumentation/gmos/components) for which
filter pairs with which grating.
