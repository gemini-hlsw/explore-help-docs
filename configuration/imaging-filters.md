# Imaging Filters

The filters this imaging observation will use, one row per filter. 
At least one filter is required; a warning icon is shown on the panel while the list is empty.

Each row has its own:

* **Filter** — chosen from the filters the instrument offers.
* **Exposure Mode**, **Signal/Noise** (or **Exp. Time**), **Number of Exp.** — the same exposure settings as elsewhere, set independently for each filter.
* **Coadds** — only shown for instruments that support co-adding exposures.

Use the ✚ row at the bottom to add another filter, and the trash icon on a row to remove it. The
same filter cannot be selected twice.

If this configuration started from the proposal's requirements, the panel header shows an icon to
revert the filter list back to its original, requirement-derived set.
