# GNIRS Decker

The decker selects which part of the focal plane the detector sees. It is derived automatically
from your other choices — for a long-slit configuration, from the combination of **Camera** and
**Prism**; for an IFU configuration, from the IFU resolution — so it does not normally need to be
set by hand.

A reset icon appears beside the field once it differs from the configuration's default, to
revert back to it.
