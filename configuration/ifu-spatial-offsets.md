# IFU Spatial Offsets

The telescope offsets executed over the course of the sequence.

Choose a named preset from the dropdown to set the whole list at once; the presets offered depend
on which IFU is selected. Once you hand-edit the list away from the active
preset's pattern, the dropdown shows **Custom**, and a revert icon appears to restore the
instrument's default pattern.

Each position has its own offset (in arcsec) and a guiding toggle (the crosshair icon) for
whether guiding is enabled while that offset position executes. Use the ✚ button to add another
position and the trash icon to remove one; the first position cannot be removed.
