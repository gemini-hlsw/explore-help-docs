# MOS Spatial Offsets

The telescope offsets executed over the course of the observation.

Choose a named preset from the dropdown or define custom offsets.

Each position has its own offset (in arcsec) and a guiding toggle (the crosshair icon) for
whether guiding is enabled while that position executes. Use the ✚ button to add another
position and the trash icon to remove one; the first position cannot be removed.
