# MOS Mask ID

The custom mask bound to this observation, chosen from the mask designs you have uploaded as attachments. 
Only masks already uploaded for the instrument this observation uses are offered; **No mask selected** clears the binding.

This picker only appears once the proposal has been accepted — for a Science program, mask
designs are only meaningful after the observation itself has been approved. Before that point,
only the **Custom Slit Width** is set, by hand. Once a mask is bound here, the slit width is taken
from the mask itself and the **Custom Slit Width** field becomes read-only.

If no masks have been uploaded yet for this instrument, the picker shows a placeholder saying so
instead of an empty list.
